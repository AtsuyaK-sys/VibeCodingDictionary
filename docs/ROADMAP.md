1. **入口を作る**（はじめてガイド、AIのしくみ）— 初心者が迷わないようにする
2. **つまずきを減らす**（エラー、コードの読み方、公開のしかた）
3. **データ寄りの内容**（データ分析・統計、スプレッドシート）— Datadreamrs の関心に合わせる
4. **既存辞典の薄い所を埋める**（UI・ゲーム・素材・用語）
