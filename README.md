# Vibe Coding 辞典（VibeCodingDictionary）

AI初心者が「何があるのか」を**目で見て・言葉で**理解するための辞典集です。Datadreamrs のメンバーを主な利用者として想定しています。

AIに作りたいものを頼むとき、**名前を知らないものは頼めません**。この辞典では、デザイン・動き・音・ゲーム・データベース・セキュリティなどの「名前」と「動く見本」と「AIへの指示例」を、1か所にまとめています。

- 全 **33 冊**・すべて日本語
- ほとんどの項目に、その場で**触って試せる見本**が付いています
- 各項目の「**AIへの指示例**」は、ボタン1つでコピーできます

## 使い方

1. このページ右上の緑のボタン **Code → Download ZIP** でダウンロードします。
2. ZIP を展開して、中の **`index.html`** をダブルクリックで開きます（Chrome か Edge を推奨）。
3. はじめての方は、一覧ページ上部の **「🔰 はじめての方へ」**（[はじめてガイド](start.html)）から読んでください。作りたいもの別に、読む順番を案内します。
4. 一覧から読みたい辞典を選びます。一覧ページの上にある検索欄では、**全部の辞典（約6,000項目）をまとめて検索**できます。

インストールは不要です。ただし、フォントや一部の見本（3D・SQL など）はインターネットから部品を読み込むので、**ネットにつながった状態**で開いてください。

## 読むときの注意

- 内容は **2026年10〜11月時点**のものです。料金・サービスの仕様・AIモデルの名前は変わりやすいので、使う前に公式ページで確認してください。
- 法律・税金・決済のルールは概要の紹介です。実際にお金を扱うサービスを公開するときは、専門家や公式の情報で確認してください。
- セキュリティ辞典の攻撃の再現は、**このページの中だけで動く学習用**です。APIキーの見本はすべて架空の値です。
- 無料API辞典の見本は、外部の公開APIを実際に呼び出します。相手のサービスが止まっていると動かないことがあります。
- 表示設定（明るい/暗い）やチェックの状態は、お使いのブラウザの中だけに保存されます。外部には送信しません。
